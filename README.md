# DevPulse Dashboard

DevPulse is a full-stack developer productivity dashboard that helps individual contributors understand engineering metrics through insights and actionable suggestions.

##  Features

- View developer productivity metrics
- Backend-generated insights
- Actionable suggestions
- Individual contributor focused dashboard
- Full-stack architecture using React and Node.js

##  Metrics Included

- Lead Time
- Cycle Time
- Bug Rate
- Deployment Frequency
- PR Throughput

##  Tech Stack

### Frontend
- React.js
- Vite

### Backend
- Node.js
- Express.js
